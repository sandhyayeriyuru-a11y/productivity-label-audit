# Auditing an enterprise productivity benchmark: recovery of a formula-defined label

Code accompanying the paper *"Beyond Predictive Accuracy: Explainable AI for Detecting
Circularity in Enterprise Productivity Benchmarks."*

The audit shows that the `Productivity_Class` label of the public Kaggle
*Enterprise New Quality Productivity Dataset* is a deterministic weighted sum of seven
indicators cut at 0.50 and 0.70:

```
score = 0.25 Innovation + 0.20 AI + 0.15 Energy + 0.15 Asset
      + 0.10 Platform + 0.10 SupplyChain - 0.05 Risk
Low if score <= 0.50, High if score > 0.70, Medium otherwise
```

## Setup

```bash
pip install -r requirements.txt
```

Download the dataset as described in [`data/README.md`](data/README.md).

## Reproducing the paper

Run the scripts from the `src/` folder. Each prints its results and writes CSV files to `results/`.

| Script | Paper section | Output |
|---|---|---|
| `01_data_profile.py` | V-A, Table I, Table II, Fig. 1 | generator tests, independence check, Kruskal–Wallis effect sizes |
| `02_benchmark.py` | V-B, Table III, Figs. 5–6 | eleven classifiers tuned by nested CV; Bayesian correlated *t*-test |
| `03_explain.py` | V-C, Figs. 7–9 | EBM shape functions, ALE, permutation importance, dimension ablation |
| `04_rule_recovery.py` | V-D, Table IV, Eq. (2) | out-of-fold rule recovery, exact reproduction, sensitivity |
| `05_controls.py` | V-E, Table V | the diagnostic on positive and negative controls |

```bash
cd src
python 01_data_profile.py        # ~1 min
python 04_rule_recovery.py       # ~2 min
python 05_controls.py            # ~3 min
python 03_explain.py             # ~10 min
python 02_benchmark.py           # long; EBM and SVM dominate (use --quick for a smoke test)
```

`rule_recovery.py` contains the diagnostic itself and can be applied to any tabular dataset
with an ordinal or binary target:

```python
from rule_recovery import diagnose
result = diagnose(X, y)          # X: numeric array, y: integer classes 0..K-1
print(result["rounded"], result["n_rules"], result["exact_rule"])
```

A label is declared formula-defined when the rounded rule classifies at least 99.5% of
held-out records correctly and is identical in all 15 folds (5 folds x seeds 42, 43, 44).

## Notes

* Hyper-parameter grids, seeds and fold definitions follow Section IV of the paper.
* Results can differ in the last decimal across library versions (scikit-learn, LightGBM,
  XGBoost, InterpretML), especially for the tree ensembles and the EBM.
* The synthetic controls in `05_controls.py` are generated by the functions in that script.
